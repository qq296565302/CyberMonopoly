## 一、产品概览

### 1.1 一句话定位

藏在 VSCode 编辑器里的 A 股行情工具 — 看起来像在写代码，实际上在看盘。

### 1.2 核心卖点

| 卖点 | 说明 |
|------|------|

## 二、功能详细说明（对应网站功能板块）

### 2.1 自选股管理

**描述**: 侧边栏树形列表管理自选股，外观类似 VSCode 项目文件结构。

- 搜索添加：输入股票代码或名称，自动模糊搜索（东方财富 API）
- 实时刷新：默认 10 秒自动刷新，可配置 5-60 秒
- 排序功能：支持按名称/代码/涨跌幅排序
- 右键菜单：查看 K 线、查看资讯、查看研报、查看财务、移除自选
- 数据字段：股票名称、代码、当前价、涨跌幅（红涨绿跌 A 股风格）

**网站展示建议**: 展示侧边栏截图 + 动态添加股票的 GIF

### 2.2 K 线图 / 分时图

**描述**: 内置专业级图表面板，支持 K 线蜡烛图和分时走势线两种模式。

- **K 线图**: 日线蜡烛图 + 成交量柱状图，支持 30/60/120/250 日周期切换
- **分时图**: 当日分钟级走势线 + 成交量，红绿柱表示买卖方向
- **成交量**: 底部独立区域展示成交量柱状图，与价格图表时间轴联动同步缩放
- **图表库**: TradingView Lightweight Charts 4.x（专业金融图表库）

**网站展示建议**: 并排展示 K 线图和分时图的截图，突出专业感

### 2.3 热门股票

**描述**: 侧边栏展示三大榜单，帮助快速发现市场热点。

| 榜单 | 排序维度 | 数量 |
|------|----------|------|
| 涨幅榜 | 涨跌幅 降序 | Top 20 |
| 跌幅榜 | 涨跌幅 升序 | Top 20 |
| 换手榜 | 换手率 降序 | Top 20 |

- 热门股可直接加入自选股
- 热门股可直接打开 K 线图
- 右键支持查看个股资讯/研报/财务数据

**网站展示建议**: 展示三榜并列的侧边栏截图

### 2.4 行情概览

**描述**: 全屏概览面板，一览所有自选股实时行情。

- 快捷键 `Ctrl+Shift+Q` 打开
- 表格形式展示所有自选股的关键数据
- 自动刷新

**网站展示建议**: 展示概览面板截图

### 2.5 7x24 快讯

**描述**: 新浪财经 7x24 实时快讯，侧边栏独立面板展示。

- 每 60 秒自动刷新
- 点击可查看快讯详情
- 支持标签分类

**网站展示建议**: 展示快讯侧边栏截图

### 2.6 个股详情

**描述**: 个股深度信息面板，包含三个标签页。

| 标签页 | 内容 | 数据源 |
|--------|------|--------|
| 资讯 | 个股相关新闻列表 | 东方财富 |
| 研报 | 券商研报评级、目标价、盈利预测 | 东方财富 |
| 财务 | EPS/ROE/营收/净利润等核心指标 | 东方财富 |

- 支持分页加载
- 研报评级自动标色（买入=红色，卖出=绿色，中性=灰色）

**网站展示建议**: 展示三个标签页的截图

### 2.7 AI 助手

**描述**: 内置 LLM 聊天面板，支持 Function Calling 和快捷指令，可直接在编辑器里和 AI 对话，AI 可主动调用工具查询实时数据并联动图表。

- 快捷键 `Ctrl+Shift+A` 打开
- 支持 OpenAI 兼容 API（可对接各种 LLM 服务）
- **流式响应**：逐字输出，实时查看 AI 回复过程
- **Markdown 渲染**：支持表格、列表、加粗、代码块等富文本格式
- **Function Calling**：14 个内置工具，AI 可主动调用获取实时数据：
  - 行情查询、K 线数据、分时数据、财务数据
  - 大盘指数、涨跌分布、热门股票、板块行情
  - 个股新闻、快讯、研报、搜索
  - 图表触发（K 线图/分时图）
- **快捷指令**：14 条 `/` 指令快速发起查询：
  - `/行情` `/财报` `/K线` `/分时` `/大盘`
  - `/热门` `/板块` `/新闻` `/快讯` `/研报`
  - `/搜索` `/图表` `/帮助`
- **图表联动**：AI 可自动打开 K 线图/分时图，实现对话与图表的无缝联动
- **API Key 测试连接**：配置后可一键测试 LLM 服务连通性
- **Token 上下文管理**：自动截断历史消息，防止超出模型上下文限制
- **超时重试机制**：30 秒超时 + 1 次自动重试，提升稳定性
- **安全防护**：Prompt Injection 防护 + HTTPS 强制校验
- 自动注入用户自选股列表作为上下文
- 聊天历史持久化存储（最近 50 条）

**网站展示建议**: 展示 AI 聊天界面截图，强调"AI 主动调用工具查询实时数据"和"快捷指令一键查询"

### 2.8 异动提醒

**描述**: 价格异动时自动弹出 VSCode 原生通知。

- 支持两种触发条件：
  - **目标价触发**: 股价接近预设目标价时提醒
  - **异动百分比**: 涨跌幅超过阈值时提醒（默认 5%）
- 只在交易时段触发（9:30-11:30, 13:00-15:00）
- 5 分钟冷却防重复
- 点击通知可直接打开 K 线图

**网站展示建议**: 展示通知弹窗截图

### 2.9 老板键 (Boss Key)

**描述**: 一键隐蔽模式，瞬间降低画面视觉特征。

- 快捷键 `Alt+Shift+B` 或点击状态栏按钮
- 效果：所有面板降低饱和度，看起来像终端日志输出
- 状态栏常驻按钮，实时显示当前模式状态
- 老板键激活时按钮带黄色警告背景，便于感知

**网站展示建议**: 并排对比正常模式 vs 隐蔽模式的截图（非常有记忆点的功能）

### 2.10 状态栏行情

**描述**: VSCode 底部状态栏滚动显示自选股行情。

- 每 5 秒轮播一只股票
- 显示：涨跌图标 + 名称 + 当前价 + 涨跌幅
- 点击打开行情概览

### 2.11 电台直播

**描述**: 内置央广电台直播面板，边看盘边听经济之声，不错过任何市场动态。

- 快捷键 `Ctrl+Shift+R` 打开
- 支持三套央广节目实时收听：

| 电台 | 频率 | 简介 |
|------|------|------|
| 经济之声 | FM96.6 | 唯一覆盖全国的财经专业广播，交易日 9:15-16:00《交易实况》 |
| 中国之声 | FM106.1 | 中央人民广播电台第一套新闻综合广播 |
| 环球资讯广播 | FM90.5 | 环球资讯，轻松掌握天下事 |

- **HLS 直播流**：基于 hls.js 实时解码播放，低延迟流畅收听
- **本地代理**：内置 StreamProxy 代理服务器，绕过 WebView CORS 跨域限制
- **播放控制**：播放/暂停、音量调节、电台切换
- **视觉反馈**：播放时圆形图标脉冲动画，连接/缓冲/错误状态实时显示
- **错误恢复**：网络错误自动重连，媒体解码错误自动恢复

**网站展示建议**: 展示电台面板截图，突出"边看盘边听经济之声"的使用场景
